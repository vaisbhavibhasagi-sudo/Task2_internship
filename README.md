Task 2: Simple Classification Model

Objective: Build a machine learning model to classify Iris flower species using the Iris dataset.

Activities Performed:

Split the dataset into training and testing sets.

Built and trained a Decision Tree Classifier.

Evaluated model performance using accuracy, precision, and recall.

Tools Used: Python, Pandas, and Scikit-learn.

Outcome: Learned the basics of classification, model training, prediction, and performance evaluation.
